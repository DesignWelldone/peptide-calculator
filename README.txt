VialTrack 14.1.1

Public build. Contains no personal seed data.

This release improves light-theme readability across controls and labels.

Navigation: Home, Track, Vials, Weight, More.
Vials contains stock, active vials, reconstitution, and reconstitution history.
The Status Board is available from Home and More. It graphs recent activity and summarizes active vials, stock, recent entries, and weight trends using local records.
The app header contains light and dark appearance controls.
More contains the intranasal calculator, backup and restore, local-data reset, and version information.

Personal data stays local unless explicitly exported.
